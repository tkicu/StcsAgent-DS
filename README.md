# StcsAgent-DS
External Attack Surface Management system with intelligent agent automation.

## Features
- Asset management (domain, IP, subdomain, service)
- Vulnerability tracking (severity: critical/high/medium/low, CVE)
- Automated risk scoring per asset
- Auto-creation of remediation tasks for critical/high vulnerabilities
- Dashboard with charts (Chart.js) and top risky assets

## Quick Start
```bash
pip install -r requirements.txt
python main.py
